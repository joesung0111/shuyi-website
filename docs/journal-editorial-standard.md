# Journal 文章資料與審閱規範

目前已發布的 CMS 範例文章逐篇對照在 [`../content/editorial-evidence.json`](../content/editorial-evidence.json)，文章頁會顯示內容性質、資料依據、醫療界線、專業審閱狀態和參考資料。未登錄資料的 CMS 文章也會顯示「資料與審閱資訊待確認」，不會被呈現成已核實內容。

目前正式站另有兩筆標題／內文是測試佔位字串的 CMS 文章（`ddd`、`test01`）。它們已明確標為來源與審閱待確認；CMS 發布狀態未由本次修改代為變更。

## 編輯與發布

1. 把可查證的健康資訊與編輯提出的日常例子分開寫。來源連結必須直接支持所引用的那句話；沒有外部證據的生活安排明確標成一般建議，不冒充研究結論。
2. 每篇記錄其性質、資料依據、醫療／非醫療界線、來源和來源核對日期。
3. 只要涉及疾病、傷害、疼痛、症狀、禁忌或安全分流，標記待合格專業人員審閱；記下審閱者姓名、資格、日期及核准文字。未收到真實審閱資料前，不得寫成「已審閱」。
4. 服務事實（項目、流程、時間、價格、地址、穿著、限制）由舒逸確認。任何健康療效或適用性承諾須另外有證據及專業審閱。
5. 發布前由編輯逐段核對來源是否支持原文、連結是否可用，以及全文是否清楚區分生活建議和醫療資訊。

現有範例的公開審閱狀態均為「尚未經合格專業人員審閱」。目前的來源說明改善了可追溯性，並不表示文章已取得醫療審核或能取代專業意見。
