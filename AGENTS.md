# Project workflow

- After making a requested change in this project, commit and push it to the current working branch by default. Do not stop at local edits.
- If work is split across multiple branches or worktrees for the same request, integrate the changes into one branch before pushing so the requested result is available together.
- Keep unrelated user changes out of the commit. Report the branch and commit after pushing, and distinguish a push from deployment or public-site verification.
