SHU YI / MOTION STUDY

脊椎修復動畫風格

先比較 10 種不同的動態語言。選定編號後，我再把該風格移植到「活化調理」頁首右側。

01 / 逐節修復光環

由上而下逐節亮起，最接近「修復」的敘事。

${BONES}
REPAIR SEQUENCE

02 / 呼吸伸縮

整條脊椎像呼吸一樣收縮與展開，柔和、療癒。

${BONES}
BREATH / RESET

03 / 科技掃描線

掃描光束通過每節，洞孔被逐步校正。

${BONES}
SCAN / ALIGN

04 / 磁力對齊

散開的骨節被吸回中心，動態感最明顯。

${BONES}
MAGNETIC ALIGNMENT

05 / 軌道穩定

外圈軌道旋轉，中心脊椎逐漸穩定。

${BONES}
STABILIZE

06 / 粒子重組

虛線骨節由鬆散變清晰，偏未來科技感。

${BONES}
REBUILD / DATA

07 / 中心漣漪

從中央向外傳遞修復波，畫面較有呼吸感。

${BONES}
RIPPLE / RELEASE

08 / 骨節翻轉

每節翻轉顯示厚度，偏 3D 物件展示。

${BONES}
PLATE / ROTATE

09 / 液態波形

脊椎像流體般左右擺動，最柔軟、最生活化。

${BONES}
FLOW / MOVE

10 / 網格定位

在定位網格中由偏移回到中線，乾淨、理性。

${BONES}
POSITION / BALANCE
